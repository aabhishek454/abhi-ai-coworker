# Android

`android/` is a native Kotlin/Jetpack Compose application, not a WebView. The shell implements adaptive dark ABHI branding, a simplified office, and bottom navigation for Office, Chat, Tasks, Memory, and Settings. Target architecture uses unidirectional state, ViewModels, repository interfaces, Retrofit, an authenticated SSE client with backoff, Room cache, WorkManager, Android Keystore-backed tokens, document picker uploads, and FCM deep links. See SETUP for tooling requirements.
