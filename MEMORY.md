# Memory

Short-term conversation context, task checkpoints, long-term explicit memories, and user preferences are separate stores. Sensitive data is never silently promoted. Every durable memory records source, purpose, sensitivity, and retention metadata. Users can search, edit, export, and forget memories; deletion cascades to vector indexes and caches. Retrieval is tenant-filtered before similarity ranking. Phase 9 adds extraction and explicit “Remember this” UX.
